## 🛡️ Technical Credibility & Fact-Checking Framework

Every claim across all 100 posts has been classified into four strict credibility tiers:

1. **Tier A (Verified)**: Directly aligned with verified INDUS precision motion hardware specifications (gear ratios, backlashes, encoder counts, cycle times).
2. **Tier B (General Engineering)**: Established physical, mechanical, and kinematic principles (Euler-Lagrange equations, D-H parameters, ISO 9283 testing protocols).
3. **Tier C (Requires Confirmation)**: Emerging or custom capabilities clearly flagged with verification notes.
4. **Tier D (Qualitative Note)**: Unverified financial figures ($35k, $180k) or generic percentages have been eliminated and replaced with sound engineering physics (vibration suppression, thermal expansion offsets).

## 📊 Quality Scoring Rubric (100 Points)

Each post is evaluated against six objective criteria:
- **Technical Accuracy (25 pts)**: Verified mechanical/kinematic principles, zero false claims.
- **Content Originality (20 pts)**: Varied opening hooks, industrial failure modes, zero generic boilerplate.
- **LinkedIn Readability (15 pts)**: 110–180 words, short paragraphs, bullet points, clean transitions.
- **Audience Relevance (15 pts)**: Targeted to automation engineers, machine builders, plant managers, or CTOs.
- **Visual Quality (15 pts)**: Bespoke 1200x1200px SVGs matching the post's visual system.
- **CTA Effectiveness (10 pts)**: Concrete, valuable engineering next steps.
