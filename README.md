## 🛠️ Key Studio Capabilities

1. **Standalone HTML Pages**: Every single post is a dedicated, self-contained HTML page accessible via its direct URL (e.g. `/01-PRODUCT-SHOWCASES/precision-reducers/INDUS-LI-001.html`).
2. **Interactive Social Preview**: Features a pixel-perfect, INDUS-branded LinkedIn card with company verification, post hook, multi-paragraph caption, technical specification callouts, and simulated engagement metrics.
3. **One-Click Creator Utilities**:
   - `Copy Caption`: Copies hook, body paragraphs, and specs.
   - `Copy Hashtags`: Copies only targeted B2B hashtags.
   - `Copy Full Post`: Copies the entire formatted post ready for publishing.
   - `Download Visual`: Direct download of the 1200x1200 technical SVG artwork.
   - `Previous / Next Navigation`: Sequential browsing across all 100 assets.
4. **Content Management Dashboard (`index.html`)**:
   - Client-side instant keyword search across title, caption, hashtags, and specs.
   - Filtering by Category, Content Format, and Target Audience.
   - Device Preview Mode: Toggle between Desktop (580px) and Mobile (375px) feed widths.
   - Content Calendar: Set planned publishing dates and assign status (`Draft`, `Ready`, `Published`), persisted in browser `localStorage`.
